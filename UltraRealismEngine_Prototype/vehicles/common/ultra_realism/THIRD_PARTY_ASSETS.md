# Visual asset sources

The carburetor catalog in this version is built only from the eight OBJ models
provided locally by the mod author in `beamng_carburetors_mod`.

The previous Artec scan and its improvised Holley 1904 mapping are no longer
referenced, exported, or packaged. Static throttle linkage groups are removed
from the source meshes and replaced by native BeamNG prop meshes for the
butterfly, round slide and cable actuator.
